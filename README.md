# SimpliXio Landing Page

Static GitHub Pages site for `simplixio.pierrehenry.dev`.

## Positioning

> SimpliXio turns scattered thoughts, project noise, and open loops into 3 priorities and one next action.

## Design direction

```text
Linear clarity
+ Apple-native calmness
+ premium first impression
+ obvious product value in seconds
```

## Files

- `index.html` - page content and SEO metadata
- `styles.css` - responsive styling
- `CNAME` - GitHub Pages custom domain

## Setup on GitHub Pages

1. Create a repository for the page.
2. Add these files to the repository root.
3. In GitHub, go to **Settings > Pages**.
4. Set the source to the main branch root.
5. Set the custom domain to:

```text
simplixio.pierrehenry.dev
```

## Replace before publishing

- Replace the form action in `index.html`.
- Add a real `social-preview.png`.
- Update CTA links if you already have a waitlist, GitHub repo, Discord, or App Store URL.
